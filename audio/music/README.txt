САУНДТРЕК ИГРЫ (встроенный, без выбора папки)
Сюда кладутся треки игры. Подпапки = когда трек играет:
  d1 … d12   — свой район (1 Scrapyard … 12 The Summit)
  boss       — фаза босса (последние 10% района)
  hq         — база, карта и Чёрный Рынок
  overdrive  — во время Overdrive
  stingers   — короткие вставки 2–6 с: захват, встреча, discovery, награда
  menu       — главное меню
Список файлов — в manifest.json. Его заполняет Claude, когда ты присылаешь треки:
  {"v":1,"tracks":[{"file":"d1/rust.mp3","pool":"d1"}, ...]}
Если файлов нет — играет гул города (или тишина, как выбрано в Настройки → Звук → Фон).
Своя папка (Настройки → Звук → «Папка с музыкой…») важнее встроенного саундтрека.
